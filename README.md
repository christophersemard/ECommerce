## À propos

Cette application mobile explore la construction d'un parcours d'achat avec React Native et Expo : navigation entre les écrans, liste de produits, détails, panier et gestion d'état côté client.

## Fonctionnalités

- écran d'accueil et catalogue ;
- fiche produit ;
- ajout et retrait d'articles du panier ;
- navigation native entre les écrans ;
- état du panier géré avec Zustand ;
- interface compatible avec Expo web ou mobile.

## Lancer en local

Prérequis : Node.js, npm et Expo Go si l'application est testée sur mobile.

    npm install
    npm start

Les raccourcis Expo permettent ensuite d'ouvrir l'application dans un émulateur Android/iOS ou dans le navigateur :

    npm run android
    npm run ios
    npm run web

## Contexte

Prototype de formation consacré aux interfaces mobiles et à la gestion d'un panier. Il ne comprend pas de paiement réel ni de backend de production.
